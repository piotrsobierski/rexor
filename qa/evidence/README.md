# Dowody testów

Każde wykonanie scenariusza tworzy tu własny katalog:

`RRRR-MM-DD/<test|production>/<ID_SCENARIUSZA>/`

W środku muszą znaleźć się zrzuty `NN-opis-stanu.png` oraz `WYNIK.md` zgodny z
szablonem w [`../README.md`](../README.md). Nie zapisuj haseł, tokenów ani
danych prawdziwych klientów w obrazach ani raportach.
